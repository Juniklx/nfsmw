# NFSMW — verificações públicas

Este repositório serve apenas para testes e automações públicas do projeto NFSMW Android.

Não adicionar ISOs, APKs, assets do jogo, saves, credenciais, tokens, chaves de assinatura, logs privados ou cópias do repositório privado.

Os testes de GitHub Actions executam somente verificações com dados públicos e sem segredos. Os builds privados continuam no Kaggle/Google Drive.
